CSS هي الأداة التي تُحوّل صفحة HTML من شكل بسيط إلى صفحة جميلة واحترافية

CSS = Cascading Style Sheets (صفحات الأنماط الانسيابية) - لغة تُستخدم لتنسيق صفحات الويب بالألوان والخطوط والخلفيات والمسافات.

⭐ المقدمة: ما هي CSS؟

CSS = Cascading Style Sheets - صفحات الأنماط الانسيابية

ما هي CSS؟

CSS هي لغة تُستخدم لتنسيق صفحات الويب، مثل:

الألوان

الخطوط

الخلفيات

المسافات

الفرق بين HTML و CSS

HTML

يحدد محتوى وهيكل الصفحة

CSS

يحدد الشكل والمظهر والتصميم

HTML = محتوى | CSS = شكل وتصميم

🔹 أولًا: كيف نربط CSS بصفحة HTML؟

ثلاث طرق شهيرة لربط CSS بـ HTML

1️⃣

Internal CSS

يُكتب داخل الصفحة نفسها

<style>
  h1 { 
    color: blue; 
  }
</style>

يُكتب داخل <head></head>

2️⃣

Inline CSS

داخل الوسم نفسه

<p style="color: red;">
  نص أحمر
</p>

هذه الطريقة سريعة لكنها غير احترافية

3️⃣

External CSS

ملف خارجي (الأفضل)

/* style.css */
h1 { 
  color: green; 
}
<!-- داخل ملف HTML -->
<link rel="stylesheet" 
      href="style.css">

هذه الطريقة هي المعتمدة عالميًا

🔹 ثانيًا: محددات CSS (Selectors)

CSS تحتاج إلى اختيار العناصر المراد تنسيقها

1) محدد الوسم (Element Selector)

يستهدف جميع العناصر من نوع معين

p { 
  color: blue; 
}

يؤثر على جميع عناصر <p> في الصفحة

2) محدد الصنف (Class)

الأكثر استخدامًا عالميًا

<p class="intro">
  مرحبا!
</p>
.intro { 
  color: red; 
}

يستخدم النقطة . قبل اسم الكلاس

3) محدد المعرف (ID)

يُستخدم لعنصر واحد فقط

<h1 id="main-title">
  العنوان
</h1>
#main-title { 
  font-size: 30px; 
}

يستخدم الهاشتاج # قبل اسم الـ ID

🔹 ثالثًا: أهم الخصائص الأساسية في CSS

الخصائص الأساسية التي يحتاجها الطالب للبدء

🚀 1) الألوان (Colors)

h1 { 
  color: #006F88; 
}

طرق كتابة الألوان:

  • Hex - #RRGGBB
  • RGB - rgb(255, 0, 0)
  • RGBA - rgba(255, 0, 0, 0.5)
  • Color Name - red, blue

🚀 2) الخلفيات (Background)

body { 
  background-color: #f3f3f3; 
}
section { 
  background-image: url("bg.jpg"); 
}

🚀 3) الخطوط (Fonts)

p { 
  font-size: 18px; 
  font-family: Arial; 
  font-weight: bold; 
}

🚀 4) الحدود (Borders)

div { 
  border: 2px solid black; 
}

🚀 5) المسافات (Padding & Margin)

div { 
  padding: 20px; 
  margin: 10px; 
}

Padding: المسافة الداخلية بين المحتوى والحدود

Margin: المسافة الخارجية بين العنصر والعناصر الأخرى

🚀 6) العرض والارتفاع (Width & Height)

img { 
  width: 300px; 
  height: auto; 
}

🔹 رابعًا: مثال عملي – تحسين صفحة HTML باستخدام CSS

نرى كيف تتحول صفحة HTML بسيطة إلى صفحة جميلة باستخدام CSS

🔰 HTML

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>موقعي الأول</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>مرحبًا بكم في موقعي</h1>
    </header>
    
    <section class="about">
        <h2>نبذة عني</h2>
        <p>أنا مطور ويب مبتدئ وأتعلم HTML وCSS.</p>
    </section>
</body>
</html>

🔰 style.css

body {
    font-family: Arial;
    background-color: #f5f5f5;
    margin: 0;
}

header {
    background-color: #006F88;
    padding: 20px;
}

header h1 {
    color: white;
    text-align: center;
}

.about {
    background: white;
    padding: 20px;
    margin: 20px;
    border-radius: 8px;
}

h2 {
    color: #006F88;
}

🔹 خامسًا: مفاهيم أساسية تساعد الطالب

مفاهيم مهمة لفهم كيفية عمل CSS

1️⃣ الصندوق (CSS Box Model)

كل عنصر هو صندوق يحتوي على:

Content
  • Margin - المسافة الخارجية
  • Border - الحدود
  • Padding - المسافة الداخلية
  • Content - المحتوى

هذا المفهوم أساس تصميم أي صفحة

2️⃣ العرض الافتراضي للعناصر (Display)

أشهر قيم خاصية display:

display: block

عنصر بلوك
عنصر بلوك آخر

display: inline

عنصر
عرض
ضمني

display: inline-block

inline
block

سيأتي لاحقًا: flex و grid

3️⃣ Pseudo-classes (التأثيرات)

تأثيرات تفاعلية عند تمرير الماوس

a:hover { 
  color: red; 
}
جرب مرر الماوس فوقي!

:hover هو أشهر pseudo-class
