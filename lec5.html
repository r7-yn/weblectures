📌 أولًا: ما هي HTML؟ ولماذا نحتاجها؟

HTML = HyperText Markup Language

ما هي HTML؟

HTML هي اختصار لـ HyperText Markup Language. وهي عبارة عن وسوم (Tags) تحيط بالعناصر لتعرّف المتصفح ماذا يمثل كل جزء. 

<h1>مرحبا بكم في موقعي</h1>
<p>هذه فقرة نصية.</p>

المتصفح يقرأ الوسوم ويعرضها بشكل مرئي.

📌 ثانيًا: مكونات صفحة HTML الأساسية (Structure)

كل صفحة HTML لها هيكل أساسي ثابت

<!DOCTYPE html>
<html>
<head>
    <title>عنوان الصفحة</title>
    <meta charset="UTF-8">
</head>
<body>
    محتوى الصفحة يظهر هنا
</body>
</html>

🔍 شرح المكونات:

الوسم وظيفته
<!DOCTYPE html> يخبر المتصفح أن الصفحة HTML5
<html> العنصر الجذري لكل الصفحة
<head> يحتوي المعلومات غير المرئية للموقع
<meta> معلومات مهمة للغات والترميز
<title> يظهر في شريط المتصفح
<body> يحتوي كل ما يظهر للمستخدم

📌 ثالثًا: أهم الوسوم الأساسية في HTML

تعرف على الوسوم الأساسية المستخدمة في بناء صفحات الويب

1) العناوين (Headings)

<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<h3>عنوان صغير</h3>

h1 الأهم ← h6 الأصغر

2) الفقرات (Paragraphs)

<p>هذه فقرة نصية.</p>

3) الروابط (Links)

<a href="https://example.com">اضغط هنا</a>

4) الصور (Images)

<img src="image.jpg" alt="وصف للصورة">

src مكان الصورة

alt مهم لـ SEO ولذوي الاحتياجات

5) القوائم

قائمة غير مرتبة:

<ul>
  <li>عنصر 1</li>
  <li>عنصر 2</li>
</ul>

قائمة مرتبة:

<ol>
  <li>خطوة 1</li>
  <li>خطوة 2</li>
</ol>

6) الجداول (Tables)

<table border="1">
  <tr>
    <th>الاسم</th>
    <td>رمزي</td>
  </tr>
</table>

📌 div

استخدامه عام، لتجميع عناصر داخل حاوية:

<div>
  <h2>عنوان القسم</h2>
  <p>محتوى القسم</p>
</div>

📌 عناصر HTML الدلالية الحديثة (Semantic HTML)

تشرح معنى كل جزء من الصفحة:

الوسم معناه
<header> رأس الصفحة
<nav> قائمة التنقل
<main> المحتوى الرئيسي
<section> قسم من الصفحة
<article> مقالة
<footer> تذييل

📌 رابعًا: مثال عملي – بناء أول صفحة HTML

هذا مثال جاهز يمكن للطالب تشغيله مباشرة

كود HTML

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>موقعي الأول</title>
</head>
<body>
    <header>
        <h1>مرحبًا بكم في موقعي الأول</h1>
    </header>
    
    <section>
        <h2>نبذة عني</h2>
        <p>اسمي رمزي، وهذا أول موقع أبنيه باستخدام HTML.</p>
    </section>
    
    <section>
        <h2>روابط مهمة</h2>
        <ul>
            <li><a href="https://google.com">جوجل</a></li>
            <li><a href="https://youtube.com">يوتيوب</a></li>
        </ul>
    </section>
    
    <footer>
        <p>© 2025 جميع الحقوق محفوظة</p>
    </footer>
</body>
</html>
